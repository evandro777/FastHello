MyApp

A Linux app that is light and fast.

GitHub · Releases

Early version. Tested on Linux Mint Cinnamon.

What it does

Written in Rust with Slint, software rendering only, no async runtime.

LightSmall binary and little memory.
FastStarts quickly.

Install with Flatpak (updates itself)

This remote keeps MyApp updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists myapp https://OWNER.github.io/MyApp/myapp.flatpakrepo
flatpak install --system myapp io.github.OWNER.MyApp

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage

Download MyApp-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders.
