The starter kit for light, fast Linux apps

FastHello is a small working app and a sandbox for the controls every Fast app shares. Rust and Slint, software rendering, no async runtime.

Install Start your own app

A greeting that follows the name you type.

What the kit gives an app

One window
Starting it again raises the running window instead of opening a second one.
Safe settings
Private files, written atomically. A damaged file is kept as a backup, never overwritten.
Shared controls
Tabs, search box, filter bar, buttons and dialogs that look the same in every Fast app.
System look
Follows the system accent and light or dark mode. English and Portuguese included.
Ready to ship
Flatpak with its own signed update remote, an AppImage with delta updates, and CI.

Install with Flatpak (updates itself)

This remote keeps FastHello updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fasthello https://evandro777.github.io/FastHello/fasthello.flatpakrepo
flatpak install --system fasthello io.github.evandro777.FastHello

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage

Download FastHello-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders.

Start your own app

  1. Copy the repository and run ./prepare.sh <crate> <DisplayName> <github-owner>. It renames everything and does the first build.
  2. Replace the example pages and the icon, and fill in the text marked EDIT.
  3. Run flatpak/new-signing-key.sh, follow RELEASING.md, then tag v0.1.0.
